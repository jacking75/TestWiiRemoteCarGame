# TestWiiRemoteCarGame

보유한 Wii 리모컨과 핸들 외장을 사용하여 Windows PC에서 Three.js 웹 레이싱 게임을 만드는 기술 테스트 프로젝트다.

- [구현 계획: 장치 연결·입력 진단·조향 보정·1인용 주행 시제품·실물 검증](구현-계획-1.md)
- [게임 화면과 플레이 명세: 예상도·연습장·3바퀴 경기·보정·결과](게임-화면과-플레이-명세-2.md)

게임이 어떤 모습인지 먼저 보려면 화면·플레이 명세를 읽는다. 개발 순서를 확인하려면 구현 계획의 준비물과 연결 구조 → T01~T04 입력 검증 → T05~T09 게임 제작 → T10~T12 검증과 인계 순서로 읽는다.

![주행 화면·연습장·폐쇄 코스와 핸들 조작을 보여주는 시제품 예상도](assets/racing-prototype-board.png)

위 그림은 앞으로 만들 화면의 예상도다. 실제 게임 실행 화면이나 Wii 장치 검증 결과가 아니다. 단순 도형 자동차를 뒤에서 보며 핸들로 운전하고, 연습장에서 조작을 익힌 뒤 폐쇄 코스 3바퀴의 완주 시간을 측정하는 구성을 보여준다.

시제품은 기울기로 조향하고 버튼으로 가속·브레이크를 조작하는 1인용 아케이드 레이싱으로 계획한다. 입력 진단 화면, 자유 주행 연습장, 폐쇄 트랙 3바퀴 타임어택을 만든다. 조향은 적외선 포인팅을 사용하지 않으므로 일반 USB 센서바가 필요하지 않다. PC 블루투스의 실제 호환성은 별도로 확인한다.

웹 게임은 Three.js + TypeScript + Vite로 만들고, Wii 센서·버튼 입력은 Windows 로컬 연결 프로그램에서 WebSocket으로 전달하는 구성을 우선 검증한다. 브라우저의 Wii 직접 연결이나 Gamepad 자동 인식은 전제로 삼지 않는다.

현재는 계획 문서만 작성한 상태다. 장치 연결·프로그램 설치·게임 구현·빌드·브라우저 실행·실물 플레이는 아직 수행하지 않았다. 상세 태스크와 완료 기준은 구현 계획에서 관리한다. CI는 별도 요청 전에는 생성·수정·실행·진단하지 않는다.
